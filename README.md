BetterArcade adds host-configurable settings to the arcade machine's official minigames - Hide and Seek, Trash Zone, and Wobbly Run - exposed right in the game's own arcade settings menu, no external config file editing needed.

## Features
- Hide and Seek: seeker count, seeker speed/jump multipliers, hider speed/jump multipliers
- Trash Zone: powerup cooldown duration, whether the cooldown is powerup-specific, shoot-closed duration, conveyor speed duration/multiplier, trash spawn timing/rate
- Wobbly Run: toggle whether players can grab each other
- All settings appear directly in the arcade machine's existing per-mode settings screen

## Requirements
- Wobbly Life (via Steam)
- BepInEx 5.x
